# 🧬 Karcytics Synthetic Biology Module

[![CI/CD Pipeline](https://github.com/KalaimaranB/BioPro-SyntheticBiology/actions/workflows/release.yml/badge.svg)](https://github.com/KalaimaranB/BioPro-SyntheticBiology/actions/workflows/release.yml)

A Karcytics plugin for designing, validating, and simulating biological logic gates and synthetic genetic circuits.

## Quick Start

```bash
# Clone the repo (as a sibling of Karcytics-SDK, which this plugin depends on
# via a local editable path during development — see [tool.uv.sources] below)
git clone https://github.com/KalaimaranB/BioPro-SyntheticBiology.git
cd BioPro-SyntheticBiology

# Install dependencies (including dev tools) with uv
uv sync --all-extras

# Run tests
uv run pytest tests/ -v

# Lint, format, type-check
uv run ruff check src/ tests/
uv run ruff format src/ tests/
uv run mypy --explicit-package-bases src/
```

## Security

This plugin follows Karcytics's cryptographic trust model:

1. Every shipped source file is SHA-256 hashed into `security.json`, bound to a hash of `pyproject.toml`.
2. The ledger is signed with the developer's Ed25519 key -> `signature.bin`, chained to the Karcytics Core Authority via `trust_chain.json`.
3. On release, CI co-signs the ledger as the "Synthetic Biology CI Pipeline" identity (`.ci_keys/runner_delegation.json`) before publishing.
4. The Karcytics core verifies the full chain before loading the plugin.

To sign locally after making changes:
```bash
uv run karcytics-sdk sign .
```

To check whether the ledger still matches the working tree without re-signing:
```bash
python3 scripts/verify_security_ledger.py
```
