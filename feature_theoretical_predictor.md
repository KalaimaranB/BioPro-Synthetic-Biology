# Feature Specification: Theoretical Prediction Engine

## Overview
When a researcher designs a truly novel circuit using uncharacterized or proprietary parts, experimental literature does not exist. BioPro's **Theoretical Prediction Engine** pipes raw DNA and Protein sequences through state-of-the-art biophysical and deep learning models to predict the 5 core kinetic parameters required for ODE simulation. 

Any parameter generated by this engine is strictly tagged as `[Predicted]` in the UI to distinguish it from empirical data.

---

## 1. Translation Initiation Rate (RBS Strength)
**Parameter Computed:** `translation_rate`
**Justification:** Determines how quickly ribosomes bind to mRNA to synthesize protein. This is critical for predicting the total protein concentration in the cell given a certain mRNA level.

* **Model:** [Salis Lab RBS Calculator](https://salislab.net/software/)
* **Why this model:** It is the undisputed gold standard in synthetic biology. Instead of relying on black-box neural networks, it uses a first-principles thermodynamic model to calculate the Gibbs free energy (ΔG) of mRNA folding and 16S rRNA hybridization.
* **Computational Cost:** **Very Low**. Solves in seconds on a standard CPU.
* **Deployment & Privacy:** 
  * **Cloud:** Available via the Salis Lab REST API.
  * **Local (Privacy-Safe):** The core algorithm is open-source (Python). We can package it directly into BioPro. Users can run it 100% locally on their laptop, ensuring proprietary DNA sequences never leave their machine.

## 2. Promoter Output (y_max and y_min)
**Parameters Computed:** `y_max` (Fully ON transcription rate) and `y_min` (Basal leakiness / OFF state).
**Justification:** These establish the upper and lower bounds of the logic gate's signal. A high y_min means the gate is leaky, which causes signal degradation in deep circuits.

* **Model:** [Enformer (Google DeepMind via TensorFlow Hub)](https://tfhub.dev/deepmind/enformer/1)
* **Why this model:** Enformer uses a Transformer architecture (similar to LLMs) but trained on DNA. Because it uses self-attention, it can account for long-range enhancer/repressor interactions in the sequence, making it far more accurate than older Convolutional Neural Networks (CNNs) at predicting raw expression levels from sequence.
* **Computational Cost:** **High**. Requires GPU acceleration for reasonable inference times.
* **Deployment & Privacy:**
  * **Local (Apple Silicon / Desktop):** Enformer's weights are open-source. For Mac users, Apple's Unified Memory (e.g., M3 Pro with 24GB RAM) allows the GPU to utilize all available system memory, making it incredibly capable of running Enformer locally without needing a dedicated Nvidia card.
  * **Free Cloud (Google Colab):** For those wanting free cloud access without local setup, we can provide a one-click Google Colab notebook. Colab provides a free Nvidia T4 GPU (16GB VRAM), which is more than enough to run Enformer queries instantly in the browser.

## 3. Repressor Binding Affinity (K_d)
**Parameter Computed:** `K_d` (Dissociation Constant / Repression Threshold)
**Justification:** The K_d dictates exactly how much repressor protein is required to flip the promoter from ON to OFF. It is the core threshold of the logic gate.

* **Models:** [AlphaFold3](https://github.com/google-deepmind/alphafold3) -> [PyRosetta](https://www.pyrosetta.org/)
* **Why these models:** AlphaFold3 is the first model capable of accurately predicting 3D complexes of Protein bound to DNA. However, AF3 does not output thermodynamic energy directly. Therefore, we pipe the AF3-predicted 3D PDB structure into PyRosetta (a premier molecular modeling suite) to calculate the ΔΔG (binding free energy) of the complex. The binding energy directly converts to K_d via the equation: K_d = e^(ΔG / RT).
* **Computational Cost:** **Extremely High**. Predicting a Protein-DNA complex takes minutes to hours.
* **Deployment & Privacy:**
  * **Free Cloud (AlphaFold Server):** DeepMind recently launched the AlphaFold Server, which runs AF3 inference completely for free via a web API for non-commercial/academic use. This makes complex DNA-protein modeling accessible to everyone.
  * **Local (Privacy-Safe):** DeepMind released the open-source code for AlphaFold3. While it normally requires massive VRAM, optimized versions (like ColabFold/LocalFold) can run efficiently on Apple Silicon (M-series chips) for standard-sized proteins, keeping proprietary IP entirely local.

## 4. Cooperativity / Steepness (n)
**Parameter Computed:** `n` (Hill Coefficient)
**Justification:** Determines how "digital" the gate is. A high Hill coefficient (n > 2) means the gate switches sharply from ON to OFF, which is required for stable oscillators (like the Repressilator) and bistable toggle switches.

* **Model:** [AlphaFold Multimer](https://github.com/google-deepmind/alphafold)
* **Why this model:** The Hill coefficient in biology is primarily driven by the stoichiometry of the repressor (e.g., does it act as a monomer, dimer, or tetramer?). AlphaFold Multimer is currently the best tool to predict oligomerization states. If AF Multimer predicts a highly stable tetramer complex, the theoretical base Hill coefficient is estimated at ~4.
* **Computational Cost:** **High**. Requires GPU.
* **Deployment & Privacy:** 
  * **Free Cloud:** Easily run for free via Google Colab (ColabFold).
  * **Local (Apple Silicon):** Optimized Mac builds allow this to run locally utilizing the unified memory.

---

## Summary of the User Workflow
1. User pastes a highly proprietary sequence into BioPro.
2. User selects their **Compute Strategy** in Settings (e.g., "Local Only (High Privacy)" vs "Cloud APIs (Fast)").
3. BioPro orchestrates the pipeline:
   - Runs local RBS Calculator for Translation Rates.
   - Pings local Enformer container for Promoter strengths.
   - Pings local AF3 cluster for 3D Protein-DNA structures to derive K_d.
4. Parameters automatically populate the UI Inspector with `[Predicted]` tags.
